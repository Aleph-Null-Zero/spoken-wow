# AGENTS.md: gossip

The root `AGENTS.md` applies. This file covers `addons/Spoken_Gossip` and the dialogue core it
shares with Spoken Quests (`addons/Spoken/Dialogue/`). `docs/gossip/README.md` is the reference.
The pipeline that builds gossip lines and packs is `docs/quests/CLAUDE.md`, because Quests and
Gossip share one corpus, one set of packs and one site section.

## Rules that bite

- Spoken_Gossip is a module of Spoken and releases with it. Notes players see go under
  `## Unreleased` in `docs/spoken/CHANGELOG.md`. Its `.toc` files and the `AddonVersion` literal
  in `Environment.lua` move with Spoken's version in a release PR.
- Every Lua file in the module starts with `if not SpokenGossipEnv then return end` and
  `setfenv(1, SpokenGossipEnv)`. Without Spoken's dialogue core, `Environment.lua` defines
  nothing and every other file returns, so the module loads inert instead of erroring. The
  generated `Gossip/*.lua` files use `setfenv(1, SpokenGossipEnv.Core)` instead.
- The core's global `VoiceOver` keeps its name. Every sound pack ever built calls
  `VoiceOver.DataModules:Register(...)`, and packs on players' disks cannot follow a rename.
- `Gossip/<lang>.lua` and `Gossip/Aliases.lua` are generated by `make quests-export-gossip-text`.
  Never edit them by hand, and regenerate them after `import-locale`, a cache upload or a relink.
- `Addon:TakeOverFromQuests` copies the settings Quests used to hold, once, guarded by
  `global.fromQuests`. The saved names `GossipFrequency`, `StopAudioOnDisengage`, `OGThrall` and
  `hasSeenGossipForNPC`, and the variable `SpokenGossipSettings`, are what players already have.
  Renaming one drops their choice without an error.
- `DialogueUIReader` (`DialogueUI.lua`) is found by name by Spoken Quests' DialogueUI bridge
  (`SpokenGossipEnv.DialogueUIReader`). Renaming it or one of its functions silences gossip pages
  on DialogueUI with no error.
- The Thrall easter egg is keyed on the line's file name (`EasterEggs.lua`), and `RunSelfTest`
  uses the same name, so a renamed file breaks both.
- `Player:HoldsGossip` lists the packs that hold no gossip (`QUEST_ONLY`: Alliance, Horde,
  Shared). A new pack that holds quests alone must be added there, or the settings page and
  Show Diagnostics count it as a gossip pack.
- Gossip lines are queued with priority `low` (`Player:Prepare`): a gossip line queued behind a
  quest line yields to it and the log says `queue-outranked`.
- Ids and file names in the root `AGENTS.md` (`g:{md5}`, `g:b{id}-{voice}`, `g:{lang}-{md5}`) are
  frozen. `Aliases.lua` links lines of one moment and never renames one.

## Tests

Run each with `luajit tests/lua/<name>`; `make test-player` runs them all.

- `gossip_frequency_test.lua`: NPC Greetings values, Never and the Listen button.
- `gossip_followup_test.lua`: Once per NPC holds back the greeting only, not the pages after an
  option.
- `gossip_options_test.lua`: the settings page.
- `gossip_takeover_test.lua`: `TakeOverFromQuests`.
- `gossip_text_test.lua`: `Gossip/<lang>.lua` and `Aliases.lua` through `DataModules`.
- `greeting_first_takeover_test.lua`: Game Greeting First moving to Spoken's settings.
